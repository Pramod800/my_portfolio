# Portfolio Images

This directory contains all the images used in the portfolio website. Below is a list of required images and their recommended specifications.

## Required Images

1. **Profile Picture**
   - Filename: `profile.jpg`
   - Recommended size: 500x500px
   - Description: A professional headshot or portrait for the About section

2. **Hero Background**
   - Filename: `hero-bg.jpg`
   - Recommended size: 1920x1080px
   - Description: A background image for the hero section (can be a workspace, coding environment, or abstract design)

3. **Project Images**
   - Filenames: `project1.jpg`, `project2.jpg`, `project3.jpg`, `project4.jpg`, `project5.jpg`, `project6.jpg`
   - Recommended size: 800x600px
   - Description: Screenshots or images representing your projects

## Image Placeholder Resources

If you don't have your own images yet, you can use these resources to get placeholder images:

- [Unsplash](https://unsplash.com/) - Free high-quality stock photos
- [Pexels](https://www.pexels.com/) - Free stock photos and videos
- [Placeholder.com](https://placeholder.com/) - Simple image placeholders
- [Lorem Picsum](https://picsum.photos/) - Easy to use placeholder images

## Image Optimization

For better website performance, consider optimizing your images:

1. Use appropriate image formats (JPEG for photos, PNG for graphics with transparency)
2. Compress images to reduce file size without significant quality loss
3. Consider using WebP format for modern browsers
4. Make sure images are responsive and not larger than needed

## Adding Your Own Images

Replace the placeholder images with your own by:

1. Using the same filenames mentioned above
2. Placing them in this directory
3. Making sure they match the recommended dimensions or aspect ratios
