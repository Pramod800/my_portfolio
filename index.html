About

I started on the web, building with React, Node.js, MongoDB and Django. Since 2023 most of my work has been in Flutter and Dart.

I care about how an app is put together as much as how it looks: state kept in Bloc or Provider, data stored locally so the app works offline, and layers separated so the code stays easy to change.
